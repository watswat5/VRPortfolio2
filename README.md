# Portfolio 2 — watswat5

This portfolio contains two interactive projects:

| Demo | Project | Current state | Guide |
|---|---|---|---|
| 5 | **Freestyle Simulator** | A rap-battle game with a Unity Quest client, browser play/testing UI, and an AI server for transcription, crowd/opponent reactions, lyrics, and voice. Local and cloud voice/transcription modes are documented. | [Demo5 README](Demo5/README.md) |
| 6 | **Wi-Fi Heatmap** | A Quest mixed-reality survey prototype. The ESP32 probe clips to the **left or right controller** (or an M5StickC Plus2 rides on a controller or the wrist, tracked by hand tracking); the app uses BLE and the tracked pose plus calibration to place timestamped RSSI readings, and can measure one access point or a campus network's access points on a channel together. It is not head-mounted. **Needs a personal or unmanaged Quest 3: school-managed (ArborXR) headsets block its room and anchor access.** | [Demo6 README](Demo6/README.md) |

Each demo's README has what it is, its video and release, how to run it, its controls, how AI was used, and its attributions; longer guides are linked from there.
