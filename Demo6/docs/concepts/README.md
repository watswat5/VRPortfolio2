# Concept images and CAD history

These images record the mechanical design process; they are not dimensional drawings or
proof of printed fit. The two controller/probe concept illustrations are AI-generated; this
repository does not preserve the generator/model or prompts. They are historical right-hand
concepts, not a reference for the current mount.

| File | Description |
|---|---|
| `right-controller-wifi-probe-grip-concept.png` | Early right-controller probe concept |
| `xiao-esp32-c5-right-controller-probe-concept.png` | XIAO C5/antenna concept for the earlier right-hand layout |
| `probe-grip-cad-r01-preview.png` | First CAD preview |
| `probe-grip-cad-r02-boolean-preview.png` | Boolean geometry iteration |
| `probe-grip-cad-r03-section-boolean.png` | Section/boolean inspection |
| `probe-grip-cad-r04-extended-clamp.png` | Extended-clamp iteration |

The application now takes the probe on either controller (or the wrist). These clamshell
illustrations are retained as design history. Use [hardware/probe_mount.py](../../hardware/probe_mount.py),
the [hardware guide](../../hardware/README.md) and current [print exports](../../hardware/out/README.md)
for geometry. Do not derive antenna calibration from an illustration.
